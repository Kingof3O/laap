# 05 - Client UI Themes, Pengu Loader & LCU Integration

## Overview

In addition to in-game 3D character skins, Wildflover provides extensive customization of the League of Legends Client (the Chromium-based desktop UI / UX). It accomplishes this through two integrated channels:
1. **Pengu Loader Integration** (for visual UI injection)
2. **League Client Update (LCU) API** (for state tracking and automation)

---

## 1. Pengu Loader Integration

To restyle the League Client interface, Wildflover bundles and manages **Pengu Loader** (`v1.1.6`), an open-source plugin and JavaScript loader for the League Client:

* **Download Source:** Embedded strings reference automated fetching and updates:
  ```
  https://github.com/PenguLoader/PenguLoader/releases/download/v1.1.6/pengu-loader-v1.1.6.zip
  https://api.github.com/repos/PenguLoader/PenguLoader/releases/latest
  ```
* **Deployment Target:** Installs into the League Client directory alongside `LeagueClient.exe`.

### UI Customization Subsystem
The application exposes fine-grained control over the client's visual theme through dedicated Tauri commands:
* **Background Media & Graphics:**
  * `client_themes_pick_media` & `client_themes_save_asset`: Allows players to select custom images or looping videos as the client background.
  * `client_themes_clear_asset`: Reverts client assets to Riot defaults.
* **Audio & Atmosphere:**
  * `client_themes_set_music_options`: Injects custom audio tracks that replace default lobby and matchmaking music.
* **Typography:**
  * `client_themes_pick_font` & `client_themes_set_font_preset`: Injects custom web fonts and typography into the client's CSS stylesheet.
  * `client_themes_clear_font`: Resets font styling.
* **Transitions & Animations:**
  * `client_themes_set_transition`: Configures page transition curves and effects between client tabs (Play, Store, Collection, Profile).

## 2. Riot LCU (League Client Update) Integration

Wildflover communicates with the active League client via Riot's local LCU REST and WebSocket architecture:

### Connection & Discovery
* Scans running processes for `LeagueClientUx.exe`.
* Reads the command-line parameters or the `lockfile` generated by League:
  ```
  lockfile -> ProcessName:PID:Port:Password:Protocol
  ```
* Connects via HTTPS to `https://127.0.0.1:<port>` with self-signed certificate acceptance (Basic Auth: `riot:<password>`).
* Subscribes to the WebSocket event bus (`wss://127.0.0.1:<port>`) for real-time gameflow events.

### Automated Gameflow Tracking
* **`lcu_get_gameflow_phase`:** Monitors the state transitions:
  * `None` -> `Lobby` -> `Matchmaking` -> `ReadyCheck` -> `ChampSelect` -> `InProgress` -> `EndOfGame`.
* **Automatic Skin Mounting:** When the gameflow reaches `ChampSelect`, the app monitors the local summoner's locked champion ID. Once locked, it automatically triggers the skin staging pipeline (`activate_mods`) before `InProgress` is reached, ensuring the virtual overlay is mounted in time for the game loading screen.
* **Client Frontend Restart:**
  * Uses the internal Riot endpoint:
    ```
    POST https://127.0.0.1:<port>/riotclient/kill-and-restart-ux
    ```
    This hot-reloads the client frontend instantly when new themes or Pengu plugins are applied without requiring a full game restart.
* **Live In-Game Stats:**
  * Queries `https://127.0.0.1:2999/liveclientdata/gamestats` during active matches to verify game start and loading state.
