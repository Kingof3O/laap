# Contributing to LAAP

See [development and packaging](docs/DEVELOPMENT.md) for the build and test commands and [architecture](docs/ARCHITECTURE.md) for component ownership.

Keep desktop data and Riot credentials local. Preserve profile storage and the Offline updater identity when changing native behavior. Use isolated profile fixtures for tests and include verification results with changes affecting session management, billing, or installers.

Report security issues through the process in [SECURITY.md](SECURITY.md).
